# Ruantiblock

[Русский](#русский) | [English](README.md)

## Русский

Выборочная маршрутизация для обхода блокировок в OpenWrt.

### Отличия этого форка

Этот [форк](https://github.com/numbereleven-a/ruantiblock_openwrt_forge) основан на [оригинальном проекте gSpotx2f](https://github.com/gSpotx2f/ruantiblock_openwrt) и сохраняет совместимость с его конфигурацией.

В форке добавлены и улучшены:

* Настройки LuCI для задания лимита пользовательских списков, а также их добавления и удаления.

* Диагностика VPN-маршрутизации: при наличии данных показываются затронутый экземпляр VPN, интерфейс, таблица маршрутизации и причина ошибки.

* Раздельное отображение версий core и LuCI, а также ручная проверка по публичному GitHub Releases API. Токен, автоматическое скачивание и автоматическая установка не используются.

* Обработка устаревших данных экземпляров, пересборка пользовательской DNS-конфигурации, очистка nftables, ошибок загрузки чёрных списков, отсутствующего crontab и синхронизация с dnsmasq при запуске.

Модель маршрутизации остаётся совместимой с оригинальным проектом и использует стандартные службы и утилиты OpenWrt, включая nftables и dnsmasq.

Поддерживаются L3 VPN с маршрутизацией на сетевой интерфейс (OpenVPN, WireGuard, PPTP, sing-box в режиме TUN и другие), прозрачные прокси с перенаправлением на порт (sing-box в режиме TProxy, Xray, V2Ray, Shadowsocks-libev, Redsocks и другие), а также Tor. Трафик можно направлять по доменам и IP-адресам, используя несколько VPN или прокси с приоритетами списков.

### Архивы и установка

Выберите формат пакетов, поддерживаемый вашей версией OpenWrt, в [последнем релизе](https://github.com/numbereleven-a/ruantiblock_openwrt_forge/releases/latest):

* OpenWrt 23.05–24.10 — пакеты IPK для установки через `opkg`.

* OpenWrt 25.12 и новее — пакеты APK для установки через `apk`.

Обязательный комплект:

* `ruantiblock` — основной пакет.

* `luci-app-ruantiblock` — веб-интерфейс LuCI.

Дополнительные пакеты:

* `ruantiblock-mod-lua` — модуль обработки списков на Lua.

* `ruantiblock-mod-py` — модуль обработки списков на Python.

Подготовьте необходимые зависимости OpenWrt по инструкции в [Wiki оригинального проекта](https://github.com/gSpotx2f/ruantiblock_openwrt/wiki), скопируйте подходящие пакеты на роутер и установите обязательную пару.

В каждом архиве последнего релиза находится `SHA256SUMS` для проверки пакетов. Команды установки и обновления приведены в описании релиза.
